# SIZA

SIZA connects hosts who need home help with helpers who want fair, local work in Johannesburg and the Vaal. This repository is currently a safe prototype: public data collection remains disabled unless explicitly enabled in the environment.

## Run locally

1. Install Node.js 20 or newer and run `npm install`.
2. Keep local settings in `.env`; never commit secrets.
3. Run `npm run dev`.

Do not connect a real database, send email, or enable public prototype routes during local realignment work.
